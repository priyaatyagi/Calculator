# 1. Project Title

**Simple Calculator Web App**

A simple calculator that runs in the browser. It does basic arithmetic (add, subtract, multiply and divide) and has a button layout like a real calculator. It handles wrong input politely, for example when you divide by zero. The buttons are round, with grey number buttons and red symbol buttons.

# 2. Technologies Used

- HTML
- CSS
- JavaScript
- VS Code with Live Server extension

# 3. Setup Instructions

1. Download or clone this repository.
2. Open the folder in VS Code. It has three files: `index.html`, `style.css` and `script.js`.
3. Right-click `index.html` and choose **Open with Live Server**.

You can also just double-click `index.html` to open it in your browser. No installation is needed.
